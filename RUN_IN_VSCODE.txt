======================================================================

======================================================================

IF YOUR TERMINAL IS IN THE PARENT FOLDER (C:\Users\rohan\Downloads\innohack final\Innohack):
----------------------------------------------------------------------
Run either of these commands in your VS Code terminal:

Option A (Navigate into inner folder first):
   cd Innohack
   python api/index.py

Option B (Run directly):
   python Innohack/api/index.py


IF YOUR TERMINAL IS ALREADY INSIDE THE INNER FOLDER (Innohack):
----------------------------------------------------------------------
   python api/index.py


AFTER STARTING THE SERVER:
----------------------------------------------------------------------
Open your web browser (Chrome / Edge) or VS Code Simple Browser and go to:
   http://localhost:8000
